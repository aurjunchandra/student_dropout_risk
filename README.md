# student_dropout_risk
#project description
=======
## Research Question
Can classification algorithms predict student dropout risk from available student characteristics?

## Dataset
Kaggle: https://www.kaggle.com/competitions/studentdropout/data

Alternative dataset:
https://archive.ics.uci.edu/dataset/697/predict+students+dropout+and+academic+success

## Planned Models
- Logistic Regression
- Random Forest

## Evaluation
Accuracy, precision, recall, F1-score, ROC-AUC where appropriate, and confusion matrix.

## Project Status
Proposal and repository setup.

## Disclaimer
Predictions are experimental decision-support estimates, not definitive judgments about individual students.
